# Pratiksha Gupta — Portfolio Website

Personal portfolio website showcasing my work, projects, and experience as a Product Designer.

## Overview

This website brings together my selected design projects, case studies, skills, and professional journey.

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/pratiksha0gupta/pratiksha0gupta.github.io.git
```

Navigate to the project directory:

```bash
cd pratiksha0gupta.github.io
```

Open `index.html` in your browser to view the website.
